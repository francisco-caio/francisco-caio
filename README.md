## ⚡ Meu Diferencial
 
> **📱 → 💻 A Origem Mobile que Forjou meu Raciocínio**
>
> Antes de ter um notebook, eu já estava resolvendo problemas reais de programação na tela de 6 polegadas de um celular. Sem atalhos, sem mouse, sem IDE completa — apenas lógica pura e determinação.
> Essa experiência me ensinou que **ferramenta não é desculpa**. Quando o ambiente é limitado, o raciocínio precisa ser mais afiado. Hoje, com um setup completo, carrego esse mindset em cada linha de código que escrevo: **eficiência, foco e solução antes de tudo.**

> 💡 **Para ativar a Snake:** Crie a pasta `.github/workflows/` no seu repositório de perfil e adicione o workflow abaixo 👇
 
</div>
<details>
<summary>⚙️ <strong>Workflow para ativar a animação Snake (clique para expandir)</strong></summary>
```yaml
# .github/workflows/snake.yml
name: Generate Snake Animation
 
on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
 
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
 
      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
 
</details>
